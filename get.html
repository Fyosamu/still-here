Free · installs in two taps · no app store, no account, no APK

STILL HERE is a progressive web app, which means there is nothing to buy and nothing to download from a store. You open it once and your browser installs it to your home screen, where it sits with its own icon, its own window and all 150 reads available offline. Pick your device:

iPhone / iPad — Safari

  1. Open the app in Safari: fyosamu.github.io/still-here
  2. Tap the Share button (the square with the arrow)
  3. Scroll down and tap Add to Home Screen
  4. Tap Add — the icon is on your home screen

Android — Chrome

  1. Open the app in Chrome: fyosamu.github.io/still-here
  2. Tap the ⋮ menu in the corner
  3. Tap Install app (older versions say Add to Home screen)
  4. Confirm — it appears in your app drawer

Computer — Chrome, Edge or Brave

  1. Open the app in the browser
  2. Click the install icon at the right end of the address bar — or the ⋮ menu → Install STILL HERE
  3. Confirm — it opens in its own window and pins to your taskbar or dock

Windows — the app as a file (optional)

The install icon above is still the normal way on a PC. If you would rather have a real Windows file — an .msix you double-click, or the exact package Microsoft's Store takes — that exists too, and it is free:

  1. Download it: still-here-windows.zip — about 9 MB
  2. Unzip the file, then run install.ps1 (Windows 10 build 19041 or newer)
  3. Windows asks once to trust the package — normal for an app that is not in the Store yet
  4. It appears in the Start menu with the same icon and all 150 reads

Why there is no store listing

It runs in the browser, so there is no store fee, no review queue and no APK file to install from outside a store. Updates land the moment the page changes — you never have to update anything. Free, ad-supported, and nothing is sold or collected.
