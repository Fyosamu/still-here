# Telegram — the cheapest traffic there is

A channel is free, needs no approval, and every post carries a link straight to a
card page that now shows an ad. It is also the only channel where you can queue a
whole month in one sitting.

## Set it up once (5 minutes)

1. Telegram → **New Channel** → name `STILL HERE` → public link
   (try `t.me/still_here_reads`, then `t.me/stillhereapp` — pick whatever is free).
2. **Description:**

   ```
   150 short reads. Money, biology, motivation, and one animal you should be
   grateful you're not. One minute each. Free, works offline, no account.
   https://fyosamu.github.io/still-here/
   ```
3. Post **Day 1** from the plan, then **pin** it.
4. Add the pinned post's link to the channel's `t.me/share`… — actually simpler:
   share the channel into any group you're in, once.

## Post the month in one sitting

Open `promo/telegram-messages.txt` in Notepad (not Excel — Excel hides multi-line
cells). It is 30 blocks, marked:

```
===== DAY 1 (cards 1 2 3 4 5) =====
STILL HERE · day 1 · 5 short reads
...
```

For each block: copy from `STILL HERE` to the last link → paste into the channel →
**⏎ Schedule message** → pick the date → confirm.

| Setting | Value |
|---|---|
| Posts per day | 1 |
| Cards per post | 5 (the file already groups them) |
| Time | 17:00–19:00 in your target timezone (US morning / EU evening) |
| One full cycle | 30 days = all 150 cards, then start again at Day 1 |

Telegram has no CSV import for messages, which is why the plain-text file exists.
30 blocks takes about 20 minutes to queue.

## After the month

- Do **not** delete and repost. Edit the pinned message instead.
- When you run out, bump the day numbers and start the cycle again — the cards
  are strong enough to repeat months later.
- Reply to your own posts occasionally with the card that *continues* the thought;
  replies keep the channel alive in people's lists.

## What to watch

- **t.me links never get indexed by Google.** This channel is for direct humans,
  not SEO. The SEO work is the card pages.
- **Do not buy members.** Purchased subscribers never open anything, and Telegram
  shadow-limits channels with fake member counts — your real posts then reach
  fewer real people than before.
- If you want the channel to grow, drop the channel link as a *reply* under other
  people's posts in related groups, never as the post itself.
